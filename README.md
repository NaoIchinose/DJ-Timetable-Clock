# DJ-Timetable-Clock

DJブースに置いて使う、タイムテーブル進行用の時計です。スマホ・タブレットのブラウザで動作します(iPhone/iPad、Android)。サーバー不要で、一度開けばオフラインでも起動できます。

## 主な機能

- 現在時刻と、現在のDJの残り時間を赤の7セグで大きく表示
- 現在のDJ名、次のDJ名、枠の「開始 → 終了」時刻、進行バーを表示
- タイムテーブルの登録・編集・削除、複数イベントの保存
- 持ち時間(分)から連続した枠を一括作成
- 連続枠の自動切替(設定でOFFにすると、超過時間「+mm:ss」を表示して手動切替)
- 警告色: 残り5分で黄、残り1分で橙(しきい値は設定で変更可)
- 残り3分以下の点滅、警告時の振動(どちらも設定で任意)
- 画面ロック(長押し2秒で解除)、全画面表示
- 画面の自動消灯を防止(ブラウザの機能を使用)
- タイムテーブルのテキスト書き出し/読み込み(入力検証つき)
- 共有リンク: タイムテーブルをリンクにして他の端末へ送信(サーバー不要)
- タブレット横向きは2カラム表示

## 使い方

### 基本操作

画面は普段ボタンが隠れています。**画面を3回タップ**するとボタンが表示され、12秒で自動的に隠れます。

- 前へ / 次へ: 現在の枠を手動で移動
- 次枠−1分 / 次枠+1分: 次の枠の開始時刻を調整(押した場合など)
- 編集・設定: タイムテーブルと設定の編集
- ロック: 誤タップ防止。画面を2秒長押しで解除
- 全画面: 全画面表示の切替

### タイムテーブルの作り方

「編集・設定」を開き、次のどちらかで登録します。

**A. 持ち時間から一括作成**

開始日時を指定し、1行1枠で `DJ名|分` を入力して「この内容で作成」を押します。現在の枠は置き換わります。

```
DJ A|20
DJ B|30
DJ C|30
```

**B. 開始・終了時刻を指定して読み込み**

「書き出し・読み込み」欄に、1行1枠で `DJ名|開始|終了` を入力して「この内容で読み込む」を押します。日時は `YYYY-MM-DD HH:mm` 形式です。DJ名に「|」は使えません。

```
DJ A|2027-01-01 12:00|2027-01-01 12:20
DJ B|2027-01-01 12:20|2027-01-01 12:50
```

形式の誤り、終了が開始より前、枠の重複は、行番号つきでエラー表示されます。

### 他の端末に同じタイムテーブルを入れる(共有リンク)

データは端末ごとに保存され、端末間の自動同期はありません。共有は次の手順です。

**送る側**

1. 「編集・設定」の「共有」で「共有リンクを作る」を押す
2. 「共有メニュー」(LINE等に送信)または「コピー」で、リンクを相手に送る

**受け取る側**

- リンクを開くと、確認のあとに新しいイベントとして追加されます(既存のイベントは上書きされません)
- **iPhone/iPad でホーム画面に追加したアプリを使う場合は、リンクを開くのではなく、アプリ内の「編集・設定」→「共有」の貼り付け欄にリンクを貼って「取り込む」を押してください。** ホーム画面のアプリとSafariはデータの保存場所が別になることがあるためです(端末・OSで挙動が異なる場合があり、要確認)
- 時間変更(押し)があった場合は、変更後に共有リンクを作り直して送り直してください(リアルタイム同期はありません)

リンクにはタイムテーブルの内容(DJ名、時刻)がそのまま含まれます。リンクを知っている人は内容を読めるため、公開の場に貼らないでください。

## 公開方法(GitHub Pages)

1. このリポジトリを Public にする
2. Settings → Pages で、Branch を `main`、フォルダを `/(root)` にして保存
3. 数分後に `https://(ユーザー名).github.io/DJ-Timetable-Clock/` で公開されます
4. 端末のブラウザで一度オンラインで開き、ホーム画面に追加

GitHub の画面の文言や仕様は変わることがあるため、最新の案内を確認してください。必ず https で配信してください(オフライン機能と画面維持に必要です)。

## ファイル構成

- `index.html`: アプリ本体(HTML/CSS/JavaScript が1ファイルに入っています)
- `manifest.webmanifest`: ホーム画面追加用の設定
- `sw.js`: オフライン起動用の Service Worker
- `icon-192.png` / `icon-512.png`: アプリアイコン

すべてリポジトリの直下に置いてください。

## 更新するとき

ファイルを差し替えたら、`sw.js` の先頭付近にある `djclock-v2` の数字を上げてください(v3、v4 …)。変更しないと、端末に古い版が残ることがあります。

## 注意事項・既知の制約

- 実機での動作確認は未完了です。本番前に、使う端末で30分以上の連続表示、機内モードでの起動、画面ロック、縦横回転を確認してください。
- 画面の自動消灯防止はブラウザ・OSの対応状況に依存します。効かない場合は、端末の自動ロックを「なし」にしてください。iPhone のホーム画面からの起動では特に要確認です。
- 全画面ボタンは、ブラウザが対応している場合のみ動作します(iPhone は非対応の可能性があります)。
- 日本語・英字フォント(Google Fonts)はオンライン時のみ読み込まれ、オフライン時は端末標準のフォントになります。
- 端末の時計がずれていると、表示もずれます。使用前に端末の時刻を合わせてください。
- 複数端末のリアルタイム同期はありません。
- 初期値として、イベント用の出演者名と持ち時間のサンプルが `index.html` に含まれています。公開したくない場合は、公開前に削除してください(`GEN_DEF` の部分)。
